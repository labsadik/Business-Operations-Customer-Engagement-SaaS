## 6. Why the configuration is split

### Build time

**Build Variables and Secrets** are available while Cloudflare Workers Builds is running the build command.

Current build command:

```text
npm run build:cloudflare
```

### Runtime

**Runtime Variables and Secrets** are available to the deployed Worker after the build completes.

Current deploy command:

```text
npm run deploy:cloudflare
```

The important distinction is:

```text
Build Variables & Secrets
        ↓
Cloudflare/OpenNext build
        ↓
Deploy
        ↓
Live Worker
        ↓
Runtime Variables & Secrets
```

Build configuration alone does not replace runtime configuration.

## 7. Quick Google sign-in checklist

For the demo Worker, all three of these must exist in **Runtime Variables & Secrets**:

```text
GOOGLE_CLIENT_ID
GOOGLE_CLIENT_SECRET
GOOGLE_REDIRECT_URI
```

And the Google OAuth client must contain this exact redirect URI:

```text
https://test0001.workforrcs.workers.dev/api/auth/google/callback
```

After changing runtime variables/secrets, redeploy the Worker so the deployed version receives the current configuration.
