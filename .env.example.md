# Conventus — Local Environment Setup

Use this document as a reference for creating a local `.env.local` file. Replace placeholders with your own development values. Keep real credentials out of source control.

## Local development

For local development, create a real `.env.local` file in the repository root and use:

```env
NEXT_PUBLIC_APP_URL=http://localhost:3000
NEXT_PUBLIC_APP_NAME=Conventus

MONGODB_URI=<set-in-local-or-host-secret-store>
REDIS_URL=<your-development-redis-url>
REDIS_TOKEN=<set-in-local-or-host-secret-store>

GOOGLE_CLIENT_ID=<your-google-oauth-client-id>
GOOGLE_CLIENT_SECRET=<set-in-local-or-host-secret-store>
GOOGLE_REDIRECT_URI=http://localhost:3000/api/auth/google/callback

AUTH_SECRET=<generate-and-set-in-secret-store>
ENCRYPTION_KEY=<generate-32-byte-base64url-secret>

RAZORPAY_KEY_ID=<your-razorpay-test-key-id>
RAZORPAY_KEY_SECRET=<set-in-secret-store>
RAZORPAY_WEBHOOK_SECRET=<set-in-secret-store>

BUNNY_STORAGE_ZONE=<your-bunny-storage-zone-name>
BUNNY_STORAGE_PASSWORD=<set-in-secret-store>
BUNNY_STORAGE_ENDPOINT=https://storage.bunnycdn.com
BUNNY_VAULT_QUOTA_BYTES=5368709120
BUNNY_VAULT_MAX_FILE_BYTES=104857600

CONVENTUS_LOGO_URL=https://your-real-conventus-logo-url

# Optional Sentry error monitoring and performance tracing
NEXT_PUBLIC_SENTRY_DSN=<public-browser-dsn>
SENTRY_DSN=<server-dsn>
NEXT_PUBLIC_SENTRY_ENVIRONMENT=<browser-environment-name>
SENTRY_ENVIRONMENT=<server-environment-name>
NEXT_PUBLIC_SENTRY_RELEASE=<optional-browser-release>
SENTRY_RELEASE=<optional-server-release>
# Leave sample rates blank for defaults: 100% in development and 10% in production.
NEXT_PUBLIC_SENTRY_TRACES_SAMPLE_RATE=
SENTRY_TRACES_SAMPLE_RATE=
# Needed only for source-map uploads during builds; keep this token secret.
SENTRY_ORG=<sentry-organization-slug>
SENTRY_PROJECT=<sentry-project-slug>
SENTRY_AUTH_TOKEN=<secret-source-map-upload-token>

AXIOM_HOST=https://us-east-1.aws.edge.axiom.co
AXIOM_DATASET=test
AXIOM_TOKEN=<set-in-secret-store>
AXIOM_SERVICE_NAME=test

CRON_SECRET=<generate-and-set-in-secret-store>

NEXT_PUBLIC_UMAMI_SCRIPT_URL=https://cloud.umami.is/script.js
NEXT_PUBLIC_UMAMI_WEBSITE_ID=4be615cd-980e-45ae-b86a-028fff9c3db5

NEXT_PUBLIC_MIXPANEL_TOKEN=<optional-mixpanel-token>

NEXT_PUBLIC_CLARITY_PROJECT_ID=<optional-clarity-project-id>
```

For local development, the Google redirect URI must match:

`http://localhost:3000/api/auth/google/callback`

and must also be registered in the Google OAuth client.


Do not add the Bunny Storage password to a NEXT_PUBLIC_ variable. Company Vault is optional by plan; server routes enforce company-wide quota, per-file and uploaded-file count limits. Final uploads are streamed to Bunny Storage to avoid whole-file buffering in application memory. See features/company-vault/README.md for details.
